# :gem: Diamond Price Predictor :gem:
---
## Project Overview
This machine learning project predicts the market value of a diamond based on its quality and physical characteristics using an XGBoost Regressor. It is integrated with a flask backend and a user-friendly HTML-CSS frontend.
---
## Technologies Used
-Python

-Flask

-XGBoost

-Pandas

-NumPy

-HTML

-CSS
---
## Dataset Details
Dataset used:

https://www.kaggle.com/datasets/lovishbansal123/diamond-dataset

The features included are:

-Carat

-Cut

-Color

-Clarity

-Depth

-Table

-x, y, z dimensions
---
## ML Workflow
-Data preprocessing

-Encoding of categorical features (Cut, Color, Clarity)

-Log transformation of target variable(Price)

-Model trained using XGB Regressor

-Model evaluation

-Integrated with Flask web application

-Deployed on Render
